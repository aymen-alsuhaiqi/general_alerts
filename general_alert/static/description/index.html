General Alert

this is a general alert app for create general notifications that shows in home menu page

This module allows administrators to create general alerts or notifications that are displayed to users on the home menu page.

Key Features

Create Alerts

Easily create new alerts with specific messages and activation status.

Home Menu Display

Active alerts are prominently displayed on the Odoo home menu for visibility.

Configuration

To create alerts, navigate to Alerts -> messages .

From there, you can create, edit, activate, or deactivate alerts.
